# Changelog

## 0.1.0 (2026-11-27)

First version of tmax.net, the .NET 10 + React port of tmax.

- Runs on Windows, macOS and Linux; builds with the .NET SDK and Node.js only (no Visual Studio, no node-gyp)
- Original tmax UI on a Photino window with an embedded, token-protected backend
- Terminals with shell integration, external pane titles (TMAX_TITLE_FILE), detached windows
- Git diff, worktrees, file explorer, Backlog.md board
- Copilot CLI and Claude Code session monitors with OS notifications
- Auto-update from GitHub releases via Velopack; no telemetry
